# رُكبة — مسار التأهيل والتغذية

تطبيق ويب (صفحة واحدة) لمتابعة تأهيل الوتر الرضفي مع د. أصيل، والتغذية ونزول الوزن، وتقرير احترافي قبل كل استشارة.
يشتغل بالكامل داخل المتصفح، ما يحتاج سيرفر ولا قاعدة بيانات.

## الرفع على GitHub Pages

1. أنشئ مستودع جديد على GitHub، مثلاً `rukba`. يكدر يكون **Private** إذا حسابك يدعم Pages للمستودعات الخاصة، وإلا خلّه Public. البيانات ما تنرفع للمستودع أبداً، تبقى بجهازك.
2. ارفع كل الملفات والمجلدات كما هي (`index.html`، `sw.js`، `manifest.webmanifest`، `assets/`، `icons/`).
3. Settings ← Pages ← Source: **Deploy from a branch** ← Branch: `main` / `(root)` ← Save.
4. بعد دقيقة يصير الرابط: `https://<اسمك>.github.io/rukba/`

## التثبيت على الآيباد

افتح الرابط بـ Safari ← زر المشاركة ← **إضافة إلى الشاشة الرئيسية**. بعدها يشتغل مثل تطبيق، وحتى بدون إنترنت.

## نقل البيانات بين اللابتوب والآيباد

- **بملف:** الإعدادات ← تصدير ملف ← احفظه بـ iCloud Drive (أو AirDrop). على الجهاز الثاني: استيراد ملف ← دمج.
- **تلقائي (GitHub Gist):** الإعدادات ← المزامنة التلقائية. الصق توكن بصلاحية `gist` فقط، والتطبيق ينشئ Gist سري ويحفظ بيه. على الجهاز الثاني الصق نفس التوكن ونفس رقم الـ Gist.

## تحديث التطبيق

إذا عدّلت أي ملف، غيّر رقم `CACHE` بأول سطر في `sw.js` (مثلاً `rukba-v1.0.1`)، حتى الأجهزة تسحب النسخة الجديدة.

## الملفات

| الملف | المحتوى |
|---|---|
| `assets/data.js` | التمارين والمراحل والأغذية والوجبات، وبياناتك من ملفات الإكسل |
| `assets/app.js` | التطبيق: الصفحات والحسابات والرسوم والمزامنة |
| `assets/report.js` | تقرير الدكتور (عربي / English) |
| `assets/content.js` | المكتبة العلمية |
| `assets/app.css` | التصميم |
