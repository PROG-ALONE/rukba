# رُكبة — الطريق إلى السجدة

تطبيق متابعة تأهيل الوتر الرضفي مع د. أصيل بدار ([تحرّك](https://www.taharrak.com/)): مراحل ومستويات، وتسجيل يومي، وجدول أيام بالتمارين، وأهداف، وتمثيل تشريحي للإصابة بكل مرحلة، وتقارير للاستشارة ولكامل الرحلة.

يشتغل بالمتصفح بدون سيرفر، وكل الملفات بجذر المستودع (بدون مجلدات).

## الملفات

| الملف | المحتوى |
|---|---|
| `index.html` | التطبيق كامل |
| `data.json` | الخطة، والمستويات، والأهداف، والخط الزمني، وسجل البداية |
| `xray-both.jpg`، `xray-zoom.jpg` | صور الأشعة (3 آب 2026) |
| `sw.js`، `manifest.webmanifest`، الأيقونات | التثبيت على الآيباد والعمل بدون إنترنت |

## البيانات

- تنحفظ على الجهاز. وأول فتح ينقل تلقائياً بيانات النسخة القديمة من نفس الجهاز.
- **المزامنة بين الأجهزة:** الإعدادات ← المزامنة ← الصق توكن GitHub بصلاحية `gist`.
- **رابط الدكتور:** بعد تفعيل المزامنة يطلع بالإعدادات رابط `?d=…` للعرض فقط.

## التحديث

بعد أي تعديل، غيّر رقم `CACHE` بأول سطر في `sw.js` حتى الأجهزة تسحب النسخة الجديدة.
